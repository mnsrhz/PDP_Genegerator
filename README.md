# Product Description Writer

A client-side React app for generating optimized eCommerce product listings from structured product details, an optional image, and an optional PDF/TXT document.

## Run

```bash
npm install
npm run dev
```

Paste an OpenAI API key into the app. The key is kept only in React component state and is used directly for the OpenAI request from the browser.

## Build

```bash
npm run build
```
